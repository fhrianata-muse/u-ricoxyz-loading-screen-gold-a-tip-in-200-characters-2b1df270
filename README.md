One line, 160 characters — one loading-screen tip for stressed developers and AI coding agents:

> Tip: your agent just opened the file you were about to open. It was the wrong file. You were about to open the wrong file too — that's why you make a good team.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–200 character, single-line gate checks out at run time.
